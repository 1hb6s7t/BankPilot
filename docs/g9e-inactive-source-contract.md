# G9E：历史、引述及否定原文契约

本次改动处理 G9D 真实 raw extraction 已确认的三个语法缺口：`旧稿里写了…` 的否定历史记录、`笔记里写过…` 的过去经历记录，以及引述 `查本月账单` 时对单字“查”的识别。旧 G9/G9B/G9C/G9D fixture、标签、评分及冻结副本保持不变；本契约和纯测试不改写其原成绩。

新增 `packages/agents/src/inactive-source.ts` 为纯原文 veto 模块。`semantic-intent.ts` 仅导入/委托 `quotedRanges`、`sourceClauses`、`quoteDisposition`、`explicitlyDataOnly`、`inactiveSourceSupported`。catalog 仍由原语义层提供完整名称，memo/purpose 的合法性、逐字范围和任务归属仍先由原校验器证明。本模块不推断实体、不填金额或日期、不修复 source、不改变任务数，不授予查询或执行权限；source repair、schema 描述和系统提示由独立改动负责。

## 可接受的非现行来源

历史引述由记录来源、记录位置/过去动词、完整引述、作废/背景说明和后续否定分句组合。来源可为旧稿、草稿、笔记、文档或既有历史记录等；位置可为里/中；过去记录形式包括写了/写过/记了/记过/记录过等。新增的是这些语法成分的组合，而不是针对三个评测句子的整句白名单。

`historical` / `negated` 只在每个分句均有独立非现行依据时成为 no_action。一个开头的“已经”“不要”或模型标签不能覆盖后续新请求。完整引述内部的转折、操作和提示注入仍是数据，不能因内部出现“但给另一人转账”而激活；引号外的当前操作继续独立校验。

`quoted` 也不能只凭模型声明生效。引述命令须真实存在并完整闭合；正文余下内容须由完整历史/记录/否定 wrapper 支持，未知的引号外残余返回澄清。润色、翻译、记录等文字任务需要完整消息和完整参数边界，后续分句不能被开头的编辑动词吞掉。

引用查询识别支持“查询/查看”等既有命令和 `查` 加明确期间/账单/银行卡/理财/订阅等查询对象的形式。它只证明一段完整查询文字处于引用中，不将其 period 或其他槽位借给现行任务，也不会把“查理”等任意未知引号名称当成查询命令。

## 引号外当前操作与否定范围

模块先屏蔽完整引号内容，再检查真实分句、显式转折、后续操作连接词及完整货币边界之后的独立支付。发现当前操作时，宽泛 historical/negated/quoted 标签不得返回 no_action；正确分成独立完整 source 的当前任务，仍按原实体、数值和期间 grounding 返回 ready。

“不要再赎回”“今天不要再查本月账单”“暂时不要继续转账”“不需要现在查询…”“不要同时赎回和转账”等，先识别请求前缀、否定词和它后面的时态/顺序副词。否定前导区间内的再/继续/现在/同时属于被否定动词，不被截成新肯定命令。扫描在第一个实际动词之前结束，因此“之前已转100元再给另一个人200元”“不要继续转账再给另一个人200元”等后续独立/不明确组合仍会澄清。前缀和副词扫描均有明确小上限。

示例配对：

| 可证明非现行 | 必须保留/澄清的当前内容 |
|---|---|
| 旧稿里写了“给某人转钱”，那句现在作废；今天不要转账 | 同样历史片段之后，另给另一人转85元 |
| 笔记里写过“从T+2赎回”，这句话已经作废；现在不要赎回 | 同样历史片段之后，现在查询银行卡状态 |
| 会议记录有一句“查本月账单”；原话仅作背景；不用查询账单 | 引述后，现在查2027年3月账单 |
| 不需要现在就直接转账 | 已经转过100元，再给另一人转85元 |

## 实体与参数边界

完整已知 catalog 名称的名词引号继续作为普通实体标点处理。未知 quoted 实体保持 unresolved clarification；看起来像查询命令的未知商户/收款人名称也不能借引号变成已知实体或授权。

payload 豁免只接受与引号内部精确重合、文字逐字相符的已证明 memo/purpose span；部分范围、伪造文字或没有原文参数依据均不豁免。现行转账备注中的历史/查询命令可以是合法用户数据，但不能用备注里的另一个人、金额或历史 period 绑定现行任务。

完整 task/slot 的定位、重叠校验及全部消息覆盖仍由原 `validateSemanticIntent` 执行。模块不接受“历史任务覆盖前半句，因此遗漏后续当前任务也算完成”的解释。未闭合引用不能把剩余消息全部默认为无动作数据。

## 验证边界

新增 `tests/g9e-inactive-source.test.ts` 使用独立姓名、金额、历史记录及 raw extraction 形态。三项 red→green 对照直接调用 G9D 冻结语义副本；不导入或修改旧 fixture/评分。测试覆盖 wrapper 成分变体、历史→当前动作/查询配对、否定内部顺序副词及后续独立操作、未知引号实体、引用注入、entity/amount/period 跨任务借用、合法 memo 和 noun quote、闭合引用及 UTF-16 范围。另经真实纯 planner + intentAdapter 验证 no_action 不调度任何领域、不生成动作。

本阶段仅证明确定性来源验证和旧纯语义回归；没有调用云模型、数据库、浏览器或真实银行服务，不能代替新候选真实模型质量、持久化或资金执行验收。G9D 原截断回合仍是原截断记录，本修复不声称还原其缺失输出。
