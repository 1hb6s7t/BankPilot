# G9C 复核隔离、批量订阅与模型候选验证

本轮完成实现、独立审查、自动化与两组真实模型验证，但**候选没有达到切换门槛**。演示 API/Worker 继续运行 G9B，使用用户指定 `https://apiw.pro/v1` / `deepseek-v4.1-flash`，默认不发送 reasoning_effort。G9C 源码保留在当前工作区并冻结为实际副本；本轮没有重启演示后端、迁移或重置原数据。整体理想状态目标仍未完成。

## 实现与并行分工

语义边界交给 GPT-6.1-sol / xhigh，处理原文范围、只读卡片与多任务约束；账单解析和验证运行器交给 GPT-6.1-sol / high；模型兼容、受控浏览器和独立审查交给 GPT-6-sol / high。主 Agent 集成账单发布门禁、订阅批处理、API/UI、最终验证和切换决策。高风险原文校验使用更高推理配置；确定性事实与运行器独立成组；审查与实现分离。产品自身仍是总控、六领域与独立复核，这与开发协作分工是两个层面。

- 账单 reviewer 必须显式判断 `billQueryAligned`。对完整/部分答案复核拒绝时，摘要、证据、已完成进度、报表附件和恢复结果均不发布该答案；缺失/不支持诊断保留服务端事实，移除模型解释。API 不得重新附加被隐藏的原始报表，旧完成态/阶段绑定不符合新协议时明确拒绝。
- 商户筛选保留逗号后限定条件，未知实质条件不回退为整月汇总。但新的分句规则也造成两项已确认回归，见下文；不能把这项实现描述成已验收完成。
- 不同订阅的两项操作全部进入同一领域的精确结构约束，各自保留对象、版本、查询授权引用与独立确认。真实 API/PG 两例验证已有授权下分别取消/拦截及幂等，以及无授权目录时拒绝未知实体且零写入。
- 无查询授权的自然语言原句尚不能自动查询并接续原请求。解析器对已绑定任务的失效快照可提出查询，不等于实际入口已完成自动前置流程。
- 可选 reasoning_effort 仅在配置时发送，非法值在派发前拒绝；本轮真实业务候选通过进程环境设置 none，未改变演示 `.env`。

两次独立审查分别发现 API 重新附加报表，以及缺失诊断仍可能携带 model-explanation，均在冻结前修复。无公开的复核前实时领域事件通道；内部阶段记录保留供恢复审计，前端只读取最终结果。见[最终独立审查](evidence/2026-10-24-g9c-final-independent-review.json)。

## 模型参数探针

独立14调用的配对探针：默认结构通过4/7，none通过7/7；默认有3次截断、none无截断。默认报告正推理token，而none未报告reasoning token，必须记未知，不能写为0，也不能据此证明供应商内部确实关闭了推理。相同7任务/schema/common body，仅改变候选参数；未验证业务语义。见[探针报告](../evals/results/g9c-reasoning-probe-2026-10-24T05-53-31-242Z-65bec394-1990-4309-bff3-8da7115f655f/report.json)。

## 不切换与后续顺序

[预先协议](g9c-validation-protocol.md)要求旧25项不退步、可用性不降低、新12项全过及真实浏览器3项全过。本轮虽可用性和浏览器满足，旧通过退步且补充仅7/12，故[切换决策为不通过](evidence/2026-10-24-g9c-promotion-decision.json)。演示API/Worker继续G9B，none只存在于评测进程；不重跑覆盖本轮失败。

1. 先修复账单合法问题与展示要求的分离。bills-01正常口语收支汇总被拒，bills-03“看到金额和原始流水编号”被当成额外问题，在最大单笔解析前被拒；同输入在G9B正确、G9C错误的纯函数对照已保留于[回归定位](evidence/2026-10-24-g9c-bill-parser-regression.json)。不能恢复为无条件整月fallback。

3. 以新冻结候选做独立回归，并分开验证参数影响；完成真实模型双订阅入口、无grant查询授权与原请求接续。
4. 继续完整目标中的独立新样本、真实云故障恢复、容量、当前版本安装交付和接收方验收。当前仍没有真实银行资金接入或比赛提交证据。
