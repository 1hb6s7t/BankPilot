上一目标轮为 progress：G9C完成代码、独立审查、自动化、完整36例与12例真实模型验证、真实浏览器和失败归因；结果未满足切换门槛，演示后端保留G9B。完整项目目标仍是六领域多Agent协作、确定性事实/授权/执行、可靠恢复、独立样本与可复现交付，不以本轮修复或已见集代替整体完成。

## 固定范围

1. 修复账单合法汇总、最大单笔、类别/商户问题与展示要求组合的解析。所有实质筛选、条件、否定与第二问题必须保留；未知条件不得丢弃后回退整月汇总。期间移除必须绑定原文位置，不得改写同文商户名；时间介词只在已验证的期间边界消费，残余引号或未知限定不得生成错误零结果。使用G9C实际副本对照与独立变体测试，不修改原48题面、标签、评分器或历史结果。
2. 提取提示/结构明确单任务、集合查询与多任务范围，必要的重新提取复用provider已有2attempt/1repair，仍受每例180秒、provider60秒、semantic4096、总输出预留32768和temperature0约束。修复原文范围不能改变任务数/顺序、操作、对象身份或金额/日期/用途/备注/筹资语义；原文、否定、覆盖与来源校验保持。
3. 仅显式评测配置启用可见结构化输出观察回调。记录固定合成fixture的semantic_intent输出，UTF-8最大65536字节，超限整段省略并保留长度/摘要；不裁剪后伪装完整原文。不保存headers、key、reasoning_content或请求catalog。独立本地0600 JSONL与attemptId绑定，不进公共PlanResult/API/UI。日志写失败使评测无效，不能诱发额外HTTP重试或记为成功澄清。默认应用与环境变量不启用该回调。
4. API图版本升级为G9D，避免旧阶段按新语义重解释；旧历史报告与已完成结果保持原版本边界。

## 同版参数对照

同一冻结代码、fixture/评分器/预算，预先绑定两个provider fingerprint：用户指定apiw.pro/v1 / deepseek-v4.1-flash / json_object / thinking omitted；default省略reasoning_effort，none显式设为none。两条件均仅修改评测进程，演示.env暂不修改。

固定顺序：default完整36例已知回归 → default原12例补充集 → none完整36例 → none原12例。每例外部串行，生产域内并行保持；每组独立run目录，不覆盖、不自动补跑全轮。default业务未过也继续none同版对照；若源漂移或评测协议不完整则中止并记录，不能在运行中改代码。两条件有时间顺序差异且无重复随机化，不能宣称因果实验或统计显著性。

36例保持G9原标签、顺序和评分；12例保持G9C原题面/标签，已经执行过，只作非盲设计补充回归。两个分母和两参数条件分别报告，不能合并为一个通过率。goal-03/goal-06角色拓扑争议继续按冻结原评分失败，另列事实检查，不报调整分数。

## 验证与切换门槛

先完成纯测试、独立审查、全仓串行测试、类型/构建，再冻结实际源码副本、依赖/协议与双provider指纹。评测逐例前后校验source inventory、所有文件、fixture和manifest；none运行前核对同manifest的两份完整default报告。观察回调不改变wire、评分或预算；trace失败、不完整或无法与模型派发对应时评测无效。

候选代码至少应保留G9B全部25个旧通过，36例可评数不低于32，无额外提案/安全失败，12例补充全部通过；受控与真实云端浏览器须按选定配置另验。达不到则不切换演示后端或参数。默认优先；仅当none同版不损失任何default通过案例、可评性不降低、两个分母业务通过数均不降低，并满足上述全部门槛，才允许根据观测延迟/报告token考虑采用none。输出更短或更快不能弥补业务失败，缺失reasoning token不能当作0或推理机制证明。

报告必须保留完整分母、未尝试/不可用、安全未评分、缺失/额外提案、HTTP与起止闭合、usage缺失、全例与通过例延迟、源码漂移。原账户/回执/聊天/命令只读对照；不重置。实验不代表真实银行接入、资金交易或接收方/比赛验收。无查询授权时自动前置查询与原请求接续、独立未见样本、容量和最终交付仍保留为完整目标中的待办。
