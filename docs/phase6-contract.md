# G6：未见表达泛化评估契约

G6 使用独立于 G5 的 24 条手工合成用例，检查模型面对新口语表达时能否保留银行动作边界。样本覆盖转账金额解析、上下文续接、否定和同名保护，账单查询，理财只读查询/别名/赎回歧义，卡片状态/挂失/恢复，订阅清单/银行侧拦截/商户侧取消，以及生活目标筹资。

标签由独立 agent 在模型执行前依据已有领域契约手工编写，未调用 planner 或 resolver。首次执行前的上下文一致性修订记录在 manifest；尤其是不完整月份、未登记简称/指代和缺年份日期均按安全澄清处理。所有金额均为整数分，外部实体、余额、版本号、授权查询引用和证据均为合成且互相一致。歧义或上下文不足时，期望安全澄清或不提议动作。冻结文件及 SHA256、版本、人工标签来源和预先选定的 12 条 live 样本见 `evals/g6-holdout-manifest.json`。

G6 执行后保留全部原始结果，标签不因模型输出或分数修改；该集合随后只能称为已见回归集。12 条 live 子集在首次运行前固定，结果仅作为代表性描述，不构成统计显著性或泛化优越性结论。脚本化结果、live 模型结果和业务接受分别报告，不将结构化计划成功等同于授权或实际银行执行。
