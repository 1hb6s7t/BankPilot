# G9B 修复与已知回归协议

本阶段承接 G9 首轮暴露的问题。上一 goal turn 完成了独立新样本评测、实现评测框架并形成可追溯失败证据，分类为 progress。完整项目目标保持：六领域协作、确定性资金与授权、准确交互、可靠恢复、可复现交付与独立验收；本阶段不以已完成的局部功能重新定义成功。

## 不可变历史与新候选

G9 首轮 11/36、其 36 条输入模板与标签、评分契约、旧运行器、原 manifest、结果和独立复核记录均保留。所有后续测量都称已知回归。新源码另建 G9B 清单与副本；新运行器复用 G9 的 case 执行、评分、时间绑定、观测与调用持久账本，不复制业务规划实现。

运行器拒绝未冻结源码或 provider 参数漂移；显式指定 live 与 known-regression，外部案例串行。全例执行相同 180 秒 deadline、provider 60 秒超时、最多 2 次尝试/1 次结构修复、temperature 0、语义请求上限 4096 和每例总请求输出上限 32768。模型保持用户指定 `deepseek-v4.1-flash`；如明确调整推理参数，则记录参数与配置探针的独立证据，不称为与 G9 单因素性能比较。

## 配置对照的单独分母

先查代理和上游公开文档，不能把上游参数支持当成代理的已证实支持。必要时使用由 G8N 冻结源码生成的合成语义任务，固定任务、schema、模型、4096 输出 cap、temperature 0；原默认配置与一个有依据的候选参数分别调用，按预注册顺序交错。每种条件每题仅一次 dispatch、不自动修复或重试，独立保存请求起止、HTTP、结构校验、用量与完成原因。

对照只回答该参数是否改变观测到的推理/可用 JSON 输出，不验证完整业务正确，不与 G9 的 36 条结果合并；HTTP 200 不能独自证明代理采纳了参数。缺 usage 或响应字段继续未知。任何预算变化、换模型或第二候选参数都另立实验，不能静默扩大当前实验。

## 必须验证的产品边界

- 正常备注/用途与引用命令分开；精确原文、作用域、金额、日期、收款人和筹资关系继续核对。真正歧义、未知实体、跨任务借槽、被引用/撤回/历史操作仍不产生可执行动作。
- 中文名称和明确只读问句不应被误拒。局部否定不能吞掉独立正向请求，也不能被裁剪掉后产生动作。T+N 定位规则先统一，再覆盖唯一候选、多个候选、未知名称残余与错误后缀。
- 账单提示允许的证据粒度应公开明确。前期证据不可重复计入当前消费；缺失/部分数据与真实零值分开；复核须获得状态、coverage、净额与来源事实，不允许把占位零当真实金额。
- 澄清需要指出实际缺失字段，不能仅以“返回 clarification”代替交互质量。有限规则仍不能证明完整自然语言或隐私安全。

## 验证顺序与证据

先跑新增成对纯测试与相关回归，独立复核实现后冻结；数据库全仓测试串行执行，类型检查和构建另存日志。真实模型回归使用原 G9 全部 36 例、原标签和原评分，保留全部失败与争议；若额外验证新质量断言则另立报告，不修改 G9 得分。必要浏览器验证使用合成独立环境，分别记录受控与真实云端路径。

使用原始完整分母报告业务通过、模型结构完成、服务不可用、安全未评分、缺少/额外提案、延迟和 usage；不把快速早停当性能优化。运行前后保留只读数据库摘要；不重置用户的账户、命令、会话或回执。阶段完成不代表整体项目完成、接收方验收或比赛提交。

## 统一的持仓定位契约

T+N 是受限的结算规则定位器。服务端当前全部持仓（含零余额或已占额）中 redemptionBusinessDays=N 必须恰好一条；不得只对可用余额筛选后声称唯一。允许空白、全角加号及固定后缀“合成理财/理财/持仓/产品”，仍需原文完整引用、实体 ID 与该唯一结果一致。多候选、多结算标记、未知名称残余、T+20 被裁成 T+2 均拒绝。领域解析与语义解析共享定位函数，并继续各自的金额/操作/作用域校验。这是对 README 示例与后续严格别名约束冲突的明确统一，不回写旧 G9 标签或分数。

账单复核使用 approved/bill/concerns 专用结构；展示文案仅由服务端事实生成，approved=false 保留。恢复签名绑定 g9b-bill-review-v1 与完整账单事实，旧自由文案缓存不兼容时明确拒绝恢复，不静默继承旧批准；历史已完成结果仍作为历史保存。

完成态 native checkpoint 也必须核对 typed bill facts binding，API 图身份升级为 G9B / state-v3；旧未完成规划若身份不兼容，返回 PLANNER_SNAPSHOT_INCOMPATIBLE，不重解释或重执行。此版本边界不修改历史已完成结果。无标点转折否定（例如“不要给甲转100元但给乙转200元”）本版保守返回明确澄清，不宣称已经支持自动拆分执行。

本轮受控浏览器额外暴露并修复资金表单初始化读响应覆盖编辑的问题；该 UI 变化纳入同一候选源码冻结。原始 5/6 记录单独保存，新延迟响应断言与受控六域复验分别计数，不合并成首次全通过。
