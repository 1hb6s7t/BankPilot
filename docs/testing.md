## 复现命令

按[部署说明](deployment.md)安装依赖并启动本项目55432端口PostgreSQL，在源码根目录执行：

```sh
pnpm test:isolated
```

该入口不读取`.env`，默认剥离云凭据，创建并绑定本次随机测试数据库。完成后按OID和owner核对并清理，只处理本次拥有的库。不要用直接`pnpm test`连接其他数据库。

单独核对新工作台纯函数展示模型：

```sh
pnpm exec vitest run tests/workbench-overview.test.ts
pnpm typecheck
pnpm build
```

定向测试覆盖精确金额及账户/余额/占额匹配边界，不能代替浏览器点击、响应式布局和授权操作验证。

## 可选扩展与限制

仓库提供受控浏览器扩展入口`pnpm test:isolated --browser`，使用前需安装相应Chromium。本轮隔离自动化未运行该扩展。云模型评测另有专用脚本，需单列配置、样本、费用与执行边界，不自动并入上述通过数量。

完整云模型驱动授权与资金执行、真正未见样本、长期稳定性和实体认证器仍需单独验收。未知结果恢复检查原请求身份与无重复付款，不用数据库回滚伪装撤销已结算交易。
