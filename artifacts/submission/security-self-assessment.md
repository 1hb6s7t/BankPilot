# 安全自评：权限分级与已知风险

## 范围

评估对象是BankPilot本地合成银行候选源码。账号、余额、支付、银行卡、订阅、理财产品及回执均为合成数据；没有真实银行、卡组织、商户或支付机构接入。此自评不构成生产环境认证、安全审计或赛事评委结论。

源码核对：`packages/core/src/index.ts`、`packages/core/src/finance.ts`、`packages/core/src/investment.ts`、`packages/core/src/management.ts`、`apps/api/src/app.ts`、`apps/api/src/webauthn.ts`、`packages/agents/src/index.ts`。本地执行凭据、`.env` 和私有状态未纳入审查材料。

## 核心风险控制事实

1. **用户与动作绑定：**动作查询使用Actor所属用户；授权哈希包含用户、动作版本、账户、收款人、金额、风险档位、期限和策略版本。改变关键动作字段会使旧证明失效。
2. **金额与预算：**使用整数分和数据库`bigint`。授权在用户级锁内重算日累计、已占用额度、可用余额和最低余额/义务保护；未来收入不增加当前可用余额。
3. **授权不可由模型代替：**AI Agent提出结构化建议，Reviewer仅审查提案，不创建资金许可。Core/API负责对动作做最终校验。
4. **重复和未知结果：**命令编号和provider请求身份支持幂等；同一provider key参数不一致会拒绝。遇到提交后超时，保留`UNKNOWN`状态并查原单。
5. **敏感运行配置：**密钥应保留在运行环境的本地忽略配置中。G9Q交付包注明不含`.env`、依赖和私有状态；本目录不存放凭据。

## 已知风险与未验收项

- **合成系统：**借贷分录、交易回执和管理操作来自本地模拟服务。它们证明沙箱内状态流，不证明真实银行清算、外部机构授权、欺诈检测、合规或资金安全。
- **模型访问与质量：**G9V此前Key下8次语义阶段HTTP403、0项可评样本为历史证据，原样保留；它不是当前Key结论。G9W新Key通过单场景（3次HTTP200、7项断言通过）及固定已知8例代表集（8/8，20次请求全成功、零重试，usage输入48222/输出14556、无缺失）。该代表集不是盲测、长期稳定性检查、真正未见样本或完整48例验收。
- **到账链范围：**G9V两项隔离scripted资金流程r2 2/2：T+0合成赎回1000元周一到账后，明确准备并确认300.25元付款，余额8000→9000→8699.75元；刷新、重登后原回执仍在。它验证当前候选沙箱内到账后独立授权付款链，不代表云端业务或真实银行清算。
- **当前版本查单恢复：**G9V的600元`TIMEOUT_AFTER_COMMIT`流程实际到`UNKNOWN`并保留占额；刷新后手动查回原单，余额为8099.75元。两个付款的提供方记录共2笔、借贷分录4条，查单没有新增授权证明。该检查是scripted/虚拟WebAuthn验收；本轮没有测试重试或进程重启。G9W云回归未执行资金授权或付款，所以没有证明完整云模型到资金执行链。
- **日历边界：**理财时间线使用`DEMO_WEEKDAYS_V1`，只按合成周一至周五日历估算，未包含法定节假日；预计到账不是可用资金。
- **验收首轮失败：**G9V首轮验收工具读取不存在的`reserved_minor`物理列并在交易前失败；修正为SQL `SUM`后r2 2/2通过。首轮失败保留，不能将r2称为首次通过。
- **虚拟验证器：**G9V资金浏览器使用虚拟WebAuthn，不能证明实体Passkey硬件/平台验证行为。
- **源码包状态与部署边界：**完整独立源码副本134文件、3420项测试、类型检查、构建和清理已有通过结果；最终ZIP与SHA256按归档清单核验。接收方复现、Windows兼容、生产环境部署控制、监控告警、密钥轮换、备份恢复、依赖漏洞管理和外部安全测试均没有本材料证明。
- **题面映射待核：**当前确认的交付要求没有给出权限分级的具体金额阈值或逐条安全判分表；需取得正式题面后逐项映射。内部代码阈值不等同于官方门槛。

## 自评结论

可以说明当前源码实现了会话归属检查、分级确认、红档Passkey强验证、资金保护、动作哈希绑定、幂等和未知结果对账等机制；G9V两条scripted资金流程r2 2/2和G9W已知8例真实模型回归8/8是独立证据。G9V旧Key的8次403保留为历史；G9W结果不能证明盲测泛化、长期稳定性或云端模型生成的资金执行闭环。完整源码副本已有134文件、3420项测试及类型检查/构建通过报告，接收方复现仍待记录。不能宣称通过正式安全认证、满足未提供的赛事阈值或接入真实金融机构。
